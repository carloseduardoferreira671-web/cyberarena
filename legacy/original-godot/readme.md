# Legacy Godot/Java artifacts

These files belonged to an earlier prototype of CyberArena and are not part of the current browser/server runtime.

They are preserved here for historical reference and future reuse. The active project entry point is `Index.html`, with `main.js`, `style.css`, `assests/`, `sounds/` and the `server/` backend.

Do not treat the legacy files as the current game implementation; some of them were incomplete or used older rules.
