# CyberArena v133 — câmera livre e pedras orgânicas

- Câmera 3D mais próxima do terreno.
- Arrasto com 1 dedo gira a visão (yaw/pitch), em vez de empurrar o mapa.
- Dois dedos fazem pan e zoom.
- Mouse wheel faz zoom.
- Rochas isoladas de landmarks não-core deixaram de usar blocos retangulares e passaram para volumes orgânicos.
- Renderer WebGL estável da v131 foi preservado.
