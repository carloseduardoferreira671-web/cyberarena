# CyberArena v89

Revisão profunda do primeiro módulo de gameplay.

## Modos

- JOGAR → Partida Normal: 16 bots, mapa 27× a tela.
- PERSONAGEM → TESTAR → Partida com Bot: 7 bots, mapa 5× a tela.
- PERSONAGEM → TESTAR → Treino Solo: 4 bots parados, mapa 5× a tela.

## Objetivo desta versão

A v89 substitui o HUD circular de aparência prototípica por controles mobile com acabamento inspirado em padrões de jogos de ação/MOBA, preserva o Player.png como personagem oficial e adiciona uma arena visível e detalhada, câmera centrada no Cyber, apresentação do mapa inteiro antes da contagem e IA adaptativa com três personalidades.

Veja `REVIEW_REPORT_v89.md` para a conferência detalhada.
