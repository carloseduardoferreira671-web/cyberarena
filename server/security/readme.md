# CyberArena Security Directory

This directory is the security reference for the current browser/server build.

- `SECURITY_ARCHITECTURE.md` — trust boundaries and data flow.
- `THREAT_MODEL.md` — threats, controls and residual risk.
- `ECONOMY_COMMANDS.md` — authoritative economic command contract.
- `TEST_PLAN.md` — repeatable security/integrity test plan.
- `OWNER_SECURITY.md` — owner/admin protection.
- `DEPLOYMENT_CHECKLIST.md` — production launch checks.
- `BACKUP_RESTORE.md` — backup and restore requirements.
- `INCIDENT_RESPONSE.md` — incident handling.
- `security-policy.json` — machine-readable production requirements.

No live credentials belong in this directory.
